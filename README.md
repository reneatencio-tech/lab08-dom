## Tarea individual: SeguriTec

SeguriTec es una aplicacion web interactiva orientada
al registro de peligros en el trabajo, desarrollada
con HTML, CSS y JavaScript.

### Funcionalidades

- Registrar nuevos peligros.
- Asignar niveles de riesgo: Alto, Medio y Bajo.
- Diferenciar los niveles mediante colores.
- Marcar peligros como controlados.
- Eliminar peligros registrados.
- Validar campos vacios.
